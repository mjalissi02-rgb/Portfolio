# Mohammed El Habib Jalissi — Portfolio

Responsive French / English portfolio using HTML, CSS and vanilla JavaScript. No build step or framework dependency.

## Preview

Run `python -m http.server 4173 --directory dist`, then open http://localhost:4173.

## Content

The supplied CV is the factual source. Translations and structured project descriptions live in `dist/app.js`; default French page content is in `dist/index.html`. Styling is in `dist/styles.css`. The original CV and portrait are in `dist/assets`.

No proficiency percentages are invented. The Yazaki OEE improvement is explicitly a potential gain. The LinkedIn profile is named in the CV but has no URL, so no LinkedIn link is guessed. GitHub profile: https://github.com/mjalissi02-rgb. Project repository: https://github.com/mjalissi02-rgb/Portfolio.git.

The French CV downloads in both interface languages. Google Fonts is optional; system sans-serif fonts provide a fallback. Contact links use email and telephone applications; no backend or contact form is required.

## Accessibility

Semantic sections, skip link, keyboard-accessible native project disclosure controls, visible focus, language state, reduced-motion support, responsive layouts. Language preference stays on the visitor's device.
